# SecureChat

A real-time chat application featuring a responsive web interface and a continuous Node.js backend. 

## 🚀 Live Deployment
* **Frontend:** Deployed via Vercel (serves the static interface instantly).
* **Backend:** Deployed via Render (handles real-time connections and API routing).

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
* **Backend:** Node.js, Express.js
* **Real-time Communication:** WebSockets / Socket.io

## 📂 Project Structure
* `/public` - Contains all client-side files (`index.html`, `style.css`, `app.js`).
* `server.js` - The main Express backend and socket initialization server.
* `package.json` - Node.js project metadata and dependencies.
